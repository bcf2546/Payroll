🔐 เข้ารหัส Web App URL สำหรับฝังในระบบ

เครื่องมือนี้แปลง URL ของ Google Apps Script เป็นข้อความเข้ารหัส (AES-256) โดยใช้ ID + Password ของระบบเป็นกุญแจ — เอาผลลัพธ์ไปวางในไฟล์ js/03-secure-url.js แล้วทุกเครื่องจะเชื่อมต่ออัตโนมัติทันทีหลัง login โดยไม่มีใครเห็น URL จริงในโค้ด

📋 ขั้นตอนต่อ:
  1. เปิดไฟล์ js/03-secure-url.js ใน GitHub (กดดินสอ ✏️ แก้ไข)
  2. แทนที่บรรทัด window.ENCRYPTED_WEBAPP_URL = ''; ด้วยบรรทัดที่ copy มา
  3. แก้เลขเวอร์ชันใน js/version.js (เช่น 3.1.0 → 3.1.1) แล้ว Commit
  4. เสร็จ! เครื่องใหม่แค่ login ก็เชื่อมต่อเองทันที
⚠️ ถ้าเปลี่ยนรหัสผ่านระบบเมื่อไหร่ ต้องมาสร้างค่าใหม่ที่นี่ด้วย (เพราะรหัสคือกุญแจถอด)

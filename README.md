## 🚀 วิธี Deploy ขึ้น GitHub Pages (ครั้งแรกครั้งเดียว)

1. สมัคร/ล็อกอิน github.com → กด **New repository**
   - ตั้งชื่อ เช่น `payroll` → เลือก **Public** → Create
2. อัพโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ลากวางได้ที่ปุ่ม "uploading an existing file")
3. ไปที่ **Settings → Pages**
   - Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
4. รอ 1-2 นาที จะได้ URL: `https://<ชื่อบัญชี>.github.io/payroll/`
5. เปิด URL → login → ไปหน้า "⚙️ ตั้งค่า" → เชื่อมต่อ Google Sheets (วาง Web App URL เดิม)

**อัพเดตครั้งถัดไป:** แก้ไฟล์ → แก้เลขเวอร์ชันใน `js/version.js` → อัพโหลดทับ → ผู้ใช้รีเฟรช 1 ครั้งได้ของใหม่ทันที (service worker เป็นแบบ network-first)

## 📊 อัพเกรด Google Apps Script เป็น v3 (โครงสร้างใหม่)

โครงสร้างใหม่: ข้อมูลแยกเป็นชีต **พนักงาน / เงินเดือน / โบนัส / Meta / Backups**
อ่านรู้เรื่อง ไม่จำกัดแถว ไม่ติดลิมิต 50,000 ตัวอักษรต่อช่องแบบเดิม

1. เปิด Google Sheet เดิมที่ใช้อยู่ → **ส่วนขยาย → Apps Script**
2. ลบโค้ดเก่าทั้งหมด → วางโค้ดจากไฟล์ `apps-script/Code.gs` (หรือ copy จากหน้าตั้งค่าในระบบ)
3. กด **Deploy → จัดการการติดตั้งใช้งาน (Manage deployments)** → กดดินสอ ✏️ →
   Version: **New version** → Deploy
   ⚠️ ใช้วิธีนี้ URL จะ**ไม่เปลี่ยน** ไม่ต้องตั้งค่าอะไรใหม่
4. เปิดระบบ → ระบบจะ **migrate ข้อมูลเก่า (Data!A1) ให้อัตโนมัติ** ตอนเชื่อมต่อครั้งแรก
   ชีตเก่าจะถูกเปลี่ยนชื่อเป็น `Data_เก่า_YYYYMMDD` เก็บไว้เผื่อฉุกเฉิน

### Backup อัตโนมัติ 30 วัน
- ทุกวันตอนบันทึกครั้งแรก ระบบ snapshot ข้อมูลทั้งหมดลงชีต "Backups" (1 แถว/วัน)
- เก็บ 30 วันล่าสุด เกินกว่านั้นลบทิ้งอัตโนมัติ (วนลูป)
- กู้คืน: หน้า "⚙️ ตั้งค่า" → "🗄️ ข้อมูลสำรองอัตโนมัติ" → โหลดรายการ → เลือกวัน → กู้คืน

## 🔐 ความปลอดภัย — อ่านก่อน Deploy

1. **วิธีแนะนำ: ฝัง URL แบบ "เข้ารหัส"** (สะดวกสุด — ทุกเครื่องแค่ login ก็ใช้ได้เลย)
   - เปิดไฟล์ `tools/encrypt-url.html` ในเบราว์เซอร์ (ดับเบิลคลิก หรือเปิดจากเว็บที่ deploy แล้ว)
   - กรอก ID / Password / Web App URL → กดเข้ารหัส → copy บรรทัดผลลัพธ์
   - วางแทนบรรทัด `window.ENCRYPTED_WEBAPP_URL = '';` ในไฟล์ `js/03-secure-url.js` → commit
   - ตั้งแต่นั้น เครื่องไหนเปิดเว็บแล้ว login ถูก ระบบถอดรหัส URL ให้เองทันที
   - สิ่งที่อยู่บน GitHub คือข้อความเข้ารหัส AES-256 (กุญแจ = รหัส login + PBKDF2 310,000 รอบ)
     คนเปิดดูโค้ดจะไม่เห็น URL จริง — **รหัสผ่านคือกุญแจจริง ห้ามรั่ว และอย่าตั้งรหัสง่าย**
   - ⚠️ ถ้าเปลี่ยนรหัสผ่านระบบ ต้องสร้างค่าเข้ารหัสใหม่ด้วยทุกครั้ง
2. **ห้ามวาง URL แบบตัวอักษรธรรมดา (plaintext) ลงในโค้ดที่อัพ GitHub**
   ใครได้ URL ไปจะอ่าน/เขียนข้อมูลพนักงานทั้งหมดได้โดยไม่ต้อง login
3. หน้า login (SHA-256) ตรวจฝั่ง browser — เมื่อใช้วิธีฝังแบบเข้ารหัส รหัสผ่านจะกลายเป็น
   กุญแจถอดรหัส URL จริงๆ ไม่ใช่แค่ม่านบังตา แต่ก็ยังโดนเดารหัสได้ถ้ารหัสอ่อน
4. ถ้าสงสัยว่า URL รั่ว: เข้า Apps Script → Deploy ใหม่เป็น URL ใหม่ → สร้างค่าเข้ารหัสใหม่ → commit
5. รหัสผ่านปัจจุบันตั้งผ่าน SHA-256 + salt ในไฟล์ `js/31-auth.js`
   เปลี่ยนรหัส: คำนวณ `sha256("ID:PASSWORD:blackchicken2568")` แล้วแทนค่า `AUTH_HASH`
   (และอย่าลืมข้อ 1 — สร้างค่า URL เข้ารหัสใหม่)

## 📱 ติดตั้งเป็นแอป (PWA)

- **มือถือ:** เปิดเว็บใน Chrome/Safari → เมนู → "เพิ่มไปยังหน้าจอหลัก"
- **คอมพิวเตอร์:** Chrome จะมีไอคอน "ติดตั้ง" ในแถบ address bar
- ใช้งานออฟไลน์ได้ (ข้อมูลเก็บใน localStorage, sync เมื่อต่อเน็ต)
- เลขเวอร์ชันแสดงที่ header และหน้า login — เช็คได้ว่าใช้ตัวล่าสุดอยู่
